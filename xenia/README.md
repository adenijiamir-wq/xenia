# XENIA - Student Marketplace

A modern Next.js marketplace for students to buy, sell products, book services, and order food delivery.

## Features

✅ Products - Browse and buy items
✅ Services - Book tutoring, repairs, and more
✅ Delivery - Order food from local spots
✅ Sell - List your items easily
✅ Accounts - Sign in, sign up, profile pages

## Quick Start

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy to Vercel

1. Push to GitHub
2. Import to Vercel
3. Deploy!

Your marketplace will be live!

---

Built with Next.js 15, TypeScript, and Tailwind CSS
